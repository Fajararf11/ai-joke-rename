# ai-joke-03 — rename

This entry writes one deterministic one-liner about AI coding agents: an agent renames a variable and makes the code less clear. It is a single line, standard library only, no network, no clock and no randomness, so every run writes the same bytes to `entry.txt` in the output directory.

Run it:

```
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Then read `out/entry.txt`.
